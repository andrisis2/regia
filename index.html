Benvenuto in Regia

Il tuo Claude, con l'agenda e gli agenti che lavorano per te. Per cominciare, incolla il codice di accesso.

Dove trovo il codice?

È un codice di GitHub, dove stanno i tuoi dati (in un archivio privato): si crea una volta sola, dal computer o dal telefono.

  1. apri github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → regia-dati
  3. Permissions → Contents: Read and write e Actions: Read and write
  4. genera, copia e incollalo qui sopra
